# Install EduSphere on Android (PWA)
1. Open https://tejaswase-glitch.github.io/edusphere/ in **Chrome**.
2. Menu (three dots) > **Install app** (or *Add to Home screen*). Samsung Internet: menu > *Add page to* > *Home screen*.
3. Open it from the home screen: it runs full-screen with its own icon.
Notes:
- Needs internet for login, lectures, classes and materials; offline you only see the page shell.
- Updates arrive automatically the next time you open it online.
- iPhone: Safari > Share > *Add to Home Screen*.
- **Screen recording on Android:** Chrome for Android does not support browser screen capture, so the Record Screen page says so. Use the phone's built-in screen recorder (swipe down twice > *Screen recorder*, include microphone), then upload the video to YouTube as Unlisted.
- Install prompt not shown? Check the site is on https and reload once; the service worker needs one visit.
